# License Manager Connectivity

## MATLAB runtime

> The MATLAB&reg; runtime as used with compiled workflows does *not* require access to
> a license manager to run compiled libraries.

## Desktop MATLAB

For details of desktop MATLAB license connectivity see:
[Configure Network License Manager for Databricks&reg;](https://github.com/mathworks-ref-arch/matlab-on-databricks/blob/main/guides/admin/configure-network-license-for-databricks.md).
