Requirements

MathWorks Products https://www.mathworks.com

  • MATLAB® R2022b or later

  • MATLAB® Compiler™, MATLAB® Compiler SDK™, Simulink® Compiler™ (optional, required for Compiler workflows only)

  • MATLAB® Coder™, Simulink® Coder™, Embedded Coder® (optional, required for Code Generation workflows only)

3rd Party Products

  • Python® (see compatible versions)

Apache Spark version

  • Apache® Spark™ 3.x or greater.
