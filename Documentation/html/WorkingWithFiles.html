Working with files

There are a number of ways to work with file and file-like interfaces in Databricks®. This can be confusing but is well documented in the included API level documentation and by Databricks.

  • Files

  • Workspaces

  • Unity Catalog

  • DBFS

    • DBFS API

  • Standard/Shared clusters & storage

Furthermore the Spark™ API accessible via Databricks connect also enable file access. MATLAB® has built in support for working directly with cloud based object storage i.e. in S3 or Azure® Blob see: https://docs.databricks.com/api/workspace/workspace
