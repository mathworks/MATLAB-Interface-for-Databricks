# Code Generation README

> Code generation is a preview feature that is not formally supported in the package.
> It may be removed without notice in a future release.

Before building and running the included example copy the `CodeGeneration` directory
to a temporary working location.

```matlab
>> copyfile(databricksRoot("examples", "Preview", "CodeGeneration"), fullfile(tempdir, "CodeGeneration"));
```

For support contact <databricks@mathworks.com>.
