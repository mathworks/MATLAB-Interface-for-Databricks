# Simulink example for Code generation in Spark

This directory contains a few examples for using Simulink&reg; and Embedded Coder&reg;
to generate a shared library from a Simulink model, and then run it in
a Spark&trade; context.

It's described in more detail in the documentation, please refer to
`<matlab-databricks>/Modules/matlab-spark-api/Documentation/CodeGeneration.md`.

For a short example of how to run the examples, see the script `run_states_one`.
