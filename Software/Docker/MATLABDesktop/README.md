# MATLAB Desktop in Databricks

This directory includes miscellaneous functionality to support building multiple
MATLAB desktop based docker images for use on Databricks.
The corresponding Docker file and associated documentation can be found in:
[https://github.com/mathworks-ref-arch/matlab-on-databricks/tree/main/resources/dockerfiles/matlab](https://github.com/mathworks-ref-arch/matlab-on-databricks/tree/main/resources/dockerfiles/matlab)
