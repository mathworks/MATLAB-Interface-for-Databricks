# MATLAB Runtime Docker file generation

This directory includes miscellaneous functionality to support building multiple
MATLAB runtime based docker images for use on Databricks.
The corresponding Docker file and associated documentation can be found in:
[https://github.com/mathworks-ref-arch/matlab-on-databricks/tree/main/resources/dockerfiles/runtime](https://github.com/mathworks-ref-arch/matlab-on-databricks/tree/main/resources/dockerfiles/runtime)

See also: [Container Services](../../../Documentation/ContainerServices.md).
